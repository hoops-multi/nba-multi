# NBA multi builder

A daily NBA multi page, published with GitHub Pages so the live score panel can reach the NBA and ESPN scoreboard feeds.

The page is a single file, `index.html`. It is refreshed three times a day (Sydney time) by a scheduled Claude task that rewrites only the `slate-data` and `history-data` JSON blocks.
Live at https://hoops-multi.github.io/nba-multi/
